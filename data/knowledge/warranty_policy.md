# 质保与维修政策

> 本文档为本店电子产品官方质保及售后维修规则。
> 最后更新：2024-01

## 电子产品质保期限

### 官方质保有效期

本店销售的**电子产品**（含耳机、蓝牙音箱、智能手表、手机配件等）享有：

- **官方质保期：自购买日起 1 年（365天）**；
- 质保起算日为订单支付成功日期，以平台订单记录为准；
- 质保凭证：平台订单截图 + 本人身份信息，**无需纸质保修卡**。

### 配件质保期

| 配件类型 | 质保期限 |
|---------|---------|
| 充电线/数据线/快充插头（易损配件） | **3个月**（90天，含随附与单独购买） |
| 耳机充电盒/充电仓（随机附赠或单独购买） | **1年**（365天，与主机同步） |
| 替换耳塞套/收纳袋等消耗品 | **1个月**（30天，仅保出厂瑕疵） |

## 免费保修界定

### 属于免费保修的情形

在质保期内（购买日起1年），以下情形可享受**免费维修**：

- 非人为原因导致的功能故障（如主板损坏、芯片故障、麦克风失灵）；
- 电池自然衰减导致续航明显不足（使用 **6个月以上**且满充电循环后，续航低于标称值的 **60%** 以下）；
- 生产工艺缺陷导致的结构问题（如卡扣松动、接口歪斜等出厂缺陷）。

### 不属于免费保修的情形（人为损坏）

以下情形**不在免费保修范围**，维修将收取材料费和工时费：

- **进水损坏**：内部腐蚀、接口氧化（不论是否有防水标注）；
- **摔落损坏**：外壳破裂、屏幕碎裂、内部元器件移位；
- **私自拆机**：开盖痕迹、维修贴撕除、非官方维修记录；
- **非正常使用**：超额电压充电、长期在极端温度（< -10°C 或 > 50°C）下使用；
- **外观人为损伤**：划痕、腐蚀、改色等不影响功能的外观问题（免费保修仅覆盖功能故障）。

## 寄修流程与时效

### 寄修申请步骤

1. **提交申请**：在 APP "我的订单 → 申请售后 → 维修"中填写故障描述，上传故障照片或视频；
2. **客服审核**：客服在 **1个工作日**内完成初步判定，通知是否符合免费保修条件；
3. **获取寄修地址**：审核通过后，系统自动下发寄修地址及运费险链接（免费保修提供平台承担运费险）；
4. **寄送商品**：消费者自行打包，使用**顺丰快递**或平台指定快递寄出，须备注工单号；
5. **维修中**：商品到达维修中心后，**2个工作日**内完成检测并告知维修方案（付费项目需消费者确认）；
6. **完成寄回**：维修完成后，**7个工作日**内寄回（特殊零件需采购的可延长至 **15个工作日**，提前通知）。

### 维修时效汇总

| 环节 | 时效 |
|------|------|
| 客服审核 | **1个工作日** |
| 到达维修中心后检测 | **2个工作日** |
| 标准维修完成并寄回 | **7个工作日** |
| 特殊零件采购后维修 | **最长15个工作日** |
| 全流程最长预估 | **约20个工作日** |

> **工作日**定义：周一至周五，法定节假日除外。节假日期间申请的，从节后第一个工作日起算。

### 质保期外付费维修

超出质保期（购买超过1年）或人为损坏，可选择**付费维修**：

- 检测费：**免费**（免费检测，不维修不收费）；
- 维修报价：检测后 **1个工作日**内给出，消费者确认后方开始维修；
- 付费维修不享受运费补贴，往返运费由消费者承担。

## 质保相关注意事项

- 质保服务**仅限原始购买者**，二手转让后质保不转移；
- 维修期间产品丢失或损坏，平台按原购买价 **100%** 赔偿；
- 维修后的产品享受 **90天维修质保**（仅针对本次维修部件）。
